# Edge Detection Techniques from Scratch

This project demonstrates the manual implementation of several fundamental edge detection techniques used in Digital Image Processing and Computer Vision. The algorithms are implemented using **Python, NumPy, OpenCV, Matplotlib, and Gradio** without relying on built-in edge detection functions.

An interactive **Gradio interface** is included to allow users to upload an image and visualize the output of each edge detection technique.

---

## 📌 Features

- Manual RGB to Grayscale conversion
- Image Gradient Calculation (Gx & Gy)
- Sobel Edge Detection
- Laplacian Edge Detection
- Laplacian of Gaussian (LoG)
- Difference of Gaussian (DoG)
- Canny Edge Detection
- Edge Detection Comparison
- Interactive Gradio Interface

---

## 📖 Implemented Tasks

### Task 1 – Image Gradient

- Manual RGB to Grayscale conversion
- Gradient in X-direction (Gx)
- Gradient in Y-direction (Gy)
- Gradient Magnitude
- Gradient Direction

---

### Task 2 – Sobel Edge Detection

- Manual Sobel X Kernel
- Manual Sobel Y Kernel
- Gradient Magnitude Calculation
- Edge Visualization

---

### Task 3 – Laplacian Edge Detection

- Manual Laplacian Kernel
- Second-order derivative edge detection
- Image Normalization

---

### Task 4 – Laplacian of Gaussian (LoG)

- Gaussian Noise Generation
- Gaussian Smoothing
- Laplacian Edge Detection
- Comparison with standard Laplacian

---

### Task 5 – Difference of Gaussian (DoG)

- First Gaussian Blur
- Second Gaussian Blur
- Difference of Gaussian
- Edge Enhancement

---

### Task 6 – Canny Edge Detection

Manual implementation of the complete Canny pipeline:

- Gaussian Smoothing
- Gradient Calculation
- Gradient Magnitude
- Gradient Direction
- Non-Maximum Suppression
- Double Thresholding
- Edge Tracking by Hysteresis

---

### Task 7 – Edge Detection Comparison

Comparison of:

- Sobel
- Laplacian
- Laplacian of Gaussian (LoG)
- Difference of Gaussian (DoG)
- Canny Edge Detection

The application also provides a brief comparison including:

- Strengths
- Limitations
- Suitable Use Cases
